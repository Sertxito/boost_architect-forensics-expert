# Playbook: No Documentation

## Principle
If there is no documentation, the system itself is the documentation.

## Evidence sources
- Repository structure.
- Package manifests.
- Build scripts.
- Pipeline definitions.
- Infrastructure files.
- Environment variables.
- API contracts.
- Database schemas.
- Logs and monitoring.
- Production configuration.

## Output
Generate living documentation with confidence levels:

- Confirmed: directly proven.
- Likely: strongly suggested but not fully proven.
- Unknown: not enough evidence.
