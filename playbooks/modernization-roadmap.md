# Playbook: Modernization Roadmap

## Roadmap structure

### Phase 0: Safety
Logging, backups, access, monitoring, reproducible builds.

### Phase 1: Understanding
Architecture reconstruction, flow mapping, dependency analysis.

### Phase 2: Stabilization
Remove deployment fragility, fix P0 risks, isolate critical flows.

### Phase 3: Modularization
Introduce boundaries, reduce coupling, create seams.

### Phase 4: Migration
Move capability by capability using strangler patterns.

### Phase 5: Optimization
Improve cost, observability, developer experience and operability.
