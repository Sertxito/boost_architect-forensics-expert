# Playbook: Unknown System

## Goal
Understand a system when nobody can explain it end-to-end.

## Steps
1. Find entry points: UI apps, APIs, jobs, queues, functions, scheduled tasks.
2. Identify runtime topology: what runs where and how it is deployed.
3. Map business flows: user journey -> service -> data -> integration.
4. Build technology inventory.
5. Map dependencies and ownership.
6. Identify critical paths and failure points.
7. Produce first architecture reconstruction.
8. Validate assumptions with code, config and runtime evidence.
9. Create risk register.
10. Produce 30-day stabilization backlog.

## Output
- Architecture sketch.
- Capability map.
- Dependency map.
- Unknowns list.
- Top 10 risks.
