# Decision Taxonomy

## KEEP
The component still provides value, is understandable, and risk is acceptable.

## REFACTOR
The component provides value but internal quality blocks maintainability.

## MODERNIZE
The capability remains valuable but architecture or technology must evolve.

## REPLATFORM
The capability is valid but runtime/infrastructure must move.

## REBUILD
The existing asset creates more risk and cost than value. Use only when evidence is strong.
