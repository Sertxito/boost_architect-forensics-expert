# Checklist: Security

- [ ] Authentication model understood
- [ ] Authorization enforced server-side
- [ ] Secrets protected
- [ ] Dependencies scanned
- [ ] CSP reviewed
- [ ] CORS reviewed
- [ ] Input validation checked
- [ ] Audit logs available
- [ ] Least privilege applied
- [ ] Incident response path known

## Evidence required
For each checked item, include file/config/runtime evidence. If evidence is missing, mark as unknown, not as passed.
