# Checklist: Data

- [ ] Databases identified
- [ ] Data ownership mapped
- [ ] Shared database risks checked
- [ ] Schema quality reviewed
- [ ] Indexes and slow queries assessed
- [ ] Data duplication identified
- [ ] Retention rules known
- [ ] Backup/restore validated
- [ ] Integration via DB detected
- [ ] Reporting dependencies mapped

## Evidence required
For each checked item, include file/config/runtime evidence. If evidence is missing, mark as unknown, not as passed.
