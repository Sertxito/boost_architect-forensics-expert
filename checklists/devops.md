# Checklist: Devops

- [ ] Build reproducible
- [ ] CI pipeline reviewed
- [ ] CD pipeline reviewed
- [ ] Rollback capability exists
- [ ] Environment parity assessed
- [ ] Secrets not hardcoded
- [ ] Tests automated
- [ ] Release approvals clear
- [ ] Infrastructure automated
- [ ] Deployment risk known

## Evidence required
For each checked item, include file/config/runtime evidence. If evidence is missing, mark as unknown, not as passed.
