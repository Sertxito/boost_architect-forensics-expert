# Checklist: Architecture Audit

- [ ] Architecture style is explicit
- [ ] Runtime components identified
- [ ] Boundaries validated against dependencies
- [ ] Data ownership is clear
- [ ] Integration patterns are documented
- [ ] Failure modes identified
- [ ] Scalability limits known
- [ ] Security controls mapped
- [ ] Deployment topology understood
- [ ] Operational model documented

## Evidence required
For each checked item, include file/config/runtime evidence. If evidence is missing, mark as unknown, not as passed.
